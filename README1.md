# Sustainability Cell – Web Convener Assignment

## Overview

This repository contains my submission for the Sustainability Cell Web Convener Assignment.

The assignment consists of:

1. Hero Section Redesign for the Sustainability Cell website.
2. Sustainability Map Proposal for IIT Bombay.

---

## Question 1: Hero Section Redesign

### Objective

Redesign the Hero Section of the Sustainability Cell website while maintaining the existing sustainability-focused theme and improving user engagement through interactive elements.

### Features Implemented

- Animated Sustainability Cell logo entrance
- Floating eco-themed background elements
- Hover interactions on CTA buttons
- Smooth scroll indicator animation
- Responsive design for desktop and mobile

### Design Approach

The redesign focuses on:
- Modern visual hierarchy
- Improved readability
- Enhanced user engagement
- Sustainability-themed animations
- Maintaining consistency with the current website identity

### Files

- `question-1-hero-redesign/prototype/`
  - HTML, CSS, and JavaScript implementation

- `question-1-hero-redesign/assets/`
  - Mockups and visual assets

- `question-1-hero-redesign/design-notes.md`
  - Design rationale and implementation details

---

## Question 2: Sustainability Map for IIT Bombay

### Objective

Develop a concept for an interactive campus map that highlights sustainability initiatives and infrastructure across IIT Bombay.

### Proposed Features

- Interactive campus map
- Sustainability location markers
- Category-based filters
- Information popups
- Search functionality
- Mobile-friendly interface

### Suggested Technology Stack

- React.js
- Leaflet.js
- OpenStreetMap
- Firebase

### Files

- `question-2-sustainability-map/proposal.md`
  - Detailed proposal

- `question-2-sustainability-map/sample-data.json`
  - Example sustainability location data

- `question-2-sustainability-map/architecture-diagram.png`
  - System architecture overview
